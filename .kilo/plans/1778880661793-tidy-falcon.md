# Admission Application Enhancement Implementation Plan (Phase 1 Only)

## Overview
This plan outlines the implementation of enhanced admission application functionality for international students (Phase 1 only).

## Phase 1: High-Confidence, Low-Risk (Quick Wins)

### 1.1 Add CountryOfOrigin and Region to AdmissionApplication
- Files: Data/Entities/AdmissionApplication.cs, Data/Entities/DocumentType.cs
- Changes: Add CountryOfOrigin (string), Region (enum: Africa, MiddleEast, Asia, Americas, Europe, Other)
- Database: New migration with nullable columns
- Contracts: Add to SaveApplicationRequest, AdmissionApplicationResponse, SubmitApplicationRequest
- Service: Add country-to-region mapping, update GetRequiredDocumentsAsync() to filter by region

### 1.2 Strengthen Visa/Immigration Fields
- Files: Data/Entities/AdmissionApplication.cs
- Changes: 
  - Add VisaStatus enum (None, Required, Applied, Approved, Rejected)
  - Add AdmissionVisaType enum (Student, Exchange, Temporary)
  - Add VisaExpiryDate, ImmigrationStatus fields
  - Convert FinancialProofAmount from string to decimal?
  - Add FinancialProofDocumentId for proof attachment
- Service: Add ValidateVisaRequirements() validation method

### 1.3 Add Country Lookup Table
- Files: New Country.cs entity, CountryController.cs endpoint
- Changes: Seeded country list (or external API integration), GET countries endpoint
- Frontend: Country dropdown with region grouping (LMS frontend located at ./LMS/LMS)

## Implementation Notes

### Database Migration Strategy
- Migration: AddCountryAndVisaFields
- Tables/Columns Added: 
  - AdmissionApplication.CountryOfOrigin (string, nullable)
  - AdmissionApplication.Region (enum, nullable) 
  - AdmissionApplication.VisaStatus (enum, nullable)
  - AdmissionApplication.VisaExpiryDate (datetime, nullable)
  - AdmissionApplication.ImmigrationStatus (string, nullable)
  - AdmissionApplication.FinancialProofAmount (decimal?, nullable)
  - AdmissionApplication.FinancialProofDocumentId (Guid, nullable)
  - Countries table (Id, Name, Region, IsActive)

### Contract Updates
- SaveApplicationRequest: Add CountryOfOrigin, Region, VisaStatus, VisaExpiryDate, ImmigrationStatus, FinancialProofAmount, FinancialProofDocumentId
- AdmissionApplicationResponse: Add same fields as above
- SubmitApplicationRequest: Add same fields as above

### Service Updates
- AdmissionService: 
  - Add country-to-region mapping utility
  - Update GetRequiredDocumentsAsync() to filter by region
  - Add ValidateVisaRequirements() method
  - Update FinancialProofAmount handling to use decimal?

### Frontend Updates (LMS/LMS)
- Country dropdown with region grouping in application forms
- Visa status selectors
- Financial proof amount input (changed to numeric)
